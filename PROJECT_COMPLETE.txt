🚀 QUICK START (5 MINUTES)
═══════════════════════════════════════════════════════════════════════════════

1. Backend Setup
   cd backend
   npm install
   cp .env.example .env
   # Edit .env with MongoDB URI
   npm run dev

2. Frontend Setup (new terminal)
   cd frontend
   npm install
   npm run dev

3. Open Browser
   http://localhost:5173

4. Test Application
   • Sign up with email/password
   • Create tasks
   • Filter and search
   • Edit and delete tasks
   • Logout and login
